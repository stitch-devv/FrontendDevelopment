# Урок 07 — Циклы for и while

## Цель урока
Повторять действия без копирования кода.

## Теория и примеры
```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i)
}
```

`for` состоит из начального значения, условия и шага. 

`while` выполняется, пока условие истинно:

```javascript
let count = 3
while (count > 0) {
    console.log(count)
    count--
}
```

Условие должно когда-нибудь стать ложным, иначе получится бесконечный цикл. 

Для перебора значений массива можно использовать `for...of`:
```javascript
const arr = [10, 20, 30];
for (const val of arr) {
  console.log(val); // 10, 20, 30
}
```

## Практика
Выведи числа от 1 до 20, посчитай сумму от 1 до 100 и перебери массив имён.
