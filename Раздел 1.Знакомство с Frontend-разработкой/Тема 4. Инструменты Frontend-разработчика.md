# Урок 03 — Инструменты Frontend-разработчика

## Цель урока

Познакомиться с основными инструментами, которые понадобятся во время обучения.

---

# 1. Что такое Code Editor?

Code Editor — программа, в которой разработчик пишет код.
Мы будем использовать: **Visual Studio Code (VS Code).**

VS Code позволяет:
* создавать файлы;
* писать код;
* работать с проектами;
* устанавливать расширения;
* использовать терминал;
* работать с Git.

---

# 2. Браузер

Для Frontend-разработчика браузер — один из главных инструментов.

Мы будем использовать его для:
* просмотра сайтов;
* проверки своей работы;
* тестирования;
* поиска ошибок;
* работы с DevTools.

Можно использовать Chrome, Edge, Firefox или другой современный браузер.

---

# 3. Chrome DevTools

*DevTools* — инструменты разработчика, встроенные в браузер.
Чтобы открыть их в Chrome нажмите на клавишу F12 или выполните комбинацию Ctrl + Shift + I

С помощью DevTools можно:
* смотреть HTML;
* смотреть CSS;
* изменять стили;
* проверять JavaScript;
* смотреть ошибки;
* анализировать запросы;
* проверять адаптивность.

---

# 4. Файлы и папки

Каждый проект состоит из файлов.

Например:
my-project/
│
├── index.html
├── style.css
└── script.js

Здесь 'my-project' папка, а index.html, style.css и script.js это файлы

---

# 5. Терминал

*Терминал* — инструмент для управления компьютером с помощью команд.

Например, команда(в терминале bash):

cd project

и компьютер переходит в папку проекта.

Команда(в терминале bash):

mkdir project

создаёт папку.

Позже терминал понадобится для:
* Git;
* Node.js;
* npm;
* запуска проектов;
* установки библиотек;
* работы с сервером.

---

# 6. Расширения VS Code

VS Code поддерживает расширения. Они могут добавлять дополнительные возможности.

Например:
* подсветку синтаксиса(кода);
* форматирование;
* автодополнение;
* работу с Git;
* удобную разработку.

Но устанавливать десятки расширений не нужно. Используй только те, которые действительно помогают.

---
