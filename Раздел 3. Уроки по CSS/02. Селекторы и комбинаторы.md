# Урок 02 — Селекторы и комбинаторы

## Цель урока
Научиться выбирать элементы для оформления.

## Теория и примеры
```css
p { color: #333; }                 /* все абзацы */
.card { padding: 20px; }            /* class */
#header { min-height: 80px; }       /* уникальный id */
h1, h2 { font-family: Arial, sans-serif; }    /* одинаковый стиль дается сразу несольким элементам; групповой селектор */
.card p { color: #555; }            /* p внутри .card(комбинатор) */
.menu > a { text-decoration: none; }/* прямые дочерние ссылки(комбинатор); т.е. стиль применится только к тем ссылкам (<a>), которые находятся на первом уровне вложенности внутри элемента с классом .menu */
h2 + p { margin-top: 0; }           /* p сразу после h2(комбинатор) */
input[type="email"] { border-color: teal; }   /* Найти на странице все поля для ввода почты и сделать их границы бирюзовыми */
```

Класс в CSS обозначается точкой(`.`), id решеткой (`#`). 
Для повторно используемого оформления обычно удобнее классы. Не создавай слишком длинные и сложные селекторы(названия class и id).

## Практика
Создай три карточки с классом `card`. Оформи их одним правилом, а одну выдели дополнительным классом.

## Домашнее задание
Сделай блок навигации, карточку профиля и список навыков. Используй селекторы элементов, классов, групповой селектор и один комбинатор.
