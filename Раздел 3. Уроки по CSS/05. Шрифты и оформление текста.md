# Урок 05 — Шрифты и оформление текста

## Цель урока
Настраивать семейство, размер, насыщенность и расстояние между строками.

## Теория и примеры
```css
body {
    font-family: Arial, Helvetica, sans-serif;
    color: #222;
    line-height: 1.6;
}
h1 {
    font-size: 2.5rem;
    font-weight: 700;
    line-height: 1.15;
    letter-spacing: -0.02em;
}
a { text-decoration: none; }
.center { text-align: center; }
```

`font-family` задаёт список запасных шрифтов, 
`font-size` — размер, 
`font-weight` — насыщенность(жирность), 
`line-height` — высоту строки, 
`letter-spacing` — интервал между символами, 
`text-align` — выравнивание.

Для длинного текста выбирай удобную длину строки и достаточный `line-height`. Учитывай лицензию при подключении сторонних шрифтов.

## Практика
Оформи статью с заголовком, подзаголовком, абзацами и ссылками. Настрой `font-family`, `font-size`, `line-height`, `font-weight` и `text-align`.
