# Урок 05 — Первый проект

## Цель урока

Создать свой первый простой веб-проект и понять, как выглядит структура Frontend-проекта.

---

# 1. Создаём папку проекта

Создай новую папку на рабочем столе и открой её в VS Code.

---

# 2. Создаём файлы

Внутри создай три файла: html, css, js

Пример: 
новая папка/      (папка)
│
├── index.html    (файл)
├── style.css     (файл)
└── script.js     (файл)

### Назвать файлы можешь как угодно, но только латинскими буквами

---

# 3. Создаём HTML

Открой свой hmtl-файл и вставь этот кусок кода:

<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Мой первый сайт</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>

    <h1>Привет! 👋</h1>

    <p>Это мой первый веб-сайт.</p>

    <button id="helloButton">
        Нажми на меня
    </button>

    <script src="script.js"></script>
</body>
</html>

---

# 4. Добавляем CSS

Открой css-файл и вставь:

body {
    font-family: Arial, sans-serif;
    text-align: center;
    padding-top: 100px;
}

h1 {
    font-size: 40px;
}

button {
    padding: 12px 24px;
    border: none;
    border-radius: 8px;
    background: black;
    color: white;
    cursor: pointer;
}

button:hover {
    opacity: 0.8;
}

---

# 5. Добавляем JavaScript

Открой javascript-файл и втсавь:

const button = document.querySelector('#helloButton')

button.addEventListener('click', () => {
    alert('Добро пожаловать во Frontend!')
})

---

# 6. Открываем сайт

Теперь проверяем результат. Сначала найди html-файл и открой его. 
В VS Code есть специальные расширения которые помогают нам в работе. Мы скачаем расширение **"Live Server"**
Набери сочетание клавиш **"Ctrl + Shift + X"** или найди **"Extensions в левой части программы(квадратные кубики)"**
Вбей в поиск название нашего расширения **"Live Server"**(Live server от Ritwick Dey, фиолетовая антенна)
Нажми на синию кнопку "install" и дождись загрузки
Когда все будет готова, вместо кнопки "install", появятся две новые кнопки "Disable" и "Uninstall". Это значит что наше расширение готова к работе
Перейди на html-файл("Ctrl + Shift + Е"), и посмотри **правую нижнюю часть экрана**, там должна появиться **"Go live"**
Нажми на него (если спросит в каком браузере открывать, выбери Google Chrome)
Сайт открывается в браузере и мы можем видеть результат

---

# 7. Что мы только что сделали?

Мы использовали сразу три технологии.

### HTML

Создал структуру:

<h1></h1>
<p></p>
<button></button>

### CSS

Изменил внешний вид:

font-size
padding
background
border-radius

### JavaScript

Добавил действие:

click

---

# 8. Как связаны файлы?

HTML подключает CSS:
<link rel="stylesheet" href="style.css">

HTML подключает JavaScript:

<script src="script.js"></script>

### При подключении файлов, пиши то название которое указал сам. Если открыл файл style.css, в подключении пиши точно так "style.css". Если у тебя другое название, пиши его
