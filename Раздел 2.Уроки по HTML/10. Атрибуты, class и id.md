# Урок 10 — Атрибуты, class и id

## Цель
Понимать атрибуты и применять `class`, `id` и `data-*`.

## Атрибуты
```html
<a href="https://example.com" target="_blank">Example</a>
<img src="photo.jpg" alt="Портрет">
<input type="email" name="email">
```
Атрибуты добавляют элементу настройки или информацию. Значения обычно заключают в кавычки("").

## Class
Класс можно повторять у многих элементов:
```html
<p class="note">Важное замечание.</p>
<p class="note">Ещё одно замечание.</p>
<article class="project-card featured">Проект</article>
```
Значение class надо давать так, чтобы при вызове класса было понятно, на какой элемент мы сейчас влияем. **Используем только латинсикие буквы!**
Все это нужно, чтобы код был понятным и чистым!

У элемента может быть несколько классов через пробел. Классы часто используются для CSS и JavaScript.

## ID
`id` должен быть уникальным в пределах документа:
```html
<section id="projects"><h2>Проекты</h2></section>
<a href="#projects">К проектам</a>
```

*При виде 'id' у элемента html, вспомните паспорта. У каждого человека свой уникальный id-номер. В программировании тоже самое, id должна быть уникальный, и НЕ ПОВТОРЯТЬСЯ как class*


## Data-атрибуты
```html
<button data-product-id="42">Посмотреть товар</button>
```
`data-*` хранит дополнительные данные для скриптов. Не помещай туда секреты: исходный HTML доступен посетителям.

## Другие атрибуты
`lang` задаёт язык фрагмента;
`hidden` скрывает элемент;
`title` может дать дополнительную подсказку, но не заменяет видимый текст или подпись;
