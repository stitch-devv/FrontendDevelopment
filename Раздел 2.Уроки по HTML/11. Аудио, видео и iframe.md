# Урок 11 — Аудио, видео и iframe

## Цель
Добавлять аудио, видео и внешний контент.

## Аудио
```html
<audio controls>
  <source src="media/music.mp3" type="audio/mpeg">
</audio>
```
Скачайте нужный файл и перетащите в проект в VS Code для избежания конфликтов в браузере
Путь к файлу должен быть правильным.

`controls` показывает элементы управления. Когда этот атрибут добавлен к тегу, браузер показывает пользователю стандартный набор кнопок и ползунков для работы с файлом:
• Кнопка воспроизведения и паузы.
• Ползунок перемотки по времени.
• Регулятор громкости звука.
• Кнопка перехода в полноэкранный режим и управления субтитрами (для тега `video`)

## Видео
```html
<video controls poster="images/cover.jpg">
  <source src="media/lesson.mp4" type="video/mp4">
</video>
```
Скачайте нужный файл и перетащите в проект в VS Code для избежания конфликтов в браузере
`poster` — изображение до воспроизведения. Субтитры можно подключить через `track`:
```html
<track src="media/subtitles-ru.vtt" kind="subtitles" srclang="ru" label="Русские субтитры" default>
```

## iframe
```html
<iframe src="https://example.com" title="Пример встроенной страницы"></iframe>
```
`iframe` встраивает(вставляет) другую страницу(независимый веб-документ, видео, карту или виджет). Укажи понятный `title`. 
Встраивай только доверенные ресурсы и понимай настройки `sandbox` и `allow`, если они нужны.

* `sandbox`
Если вы вставляете на свой сайт сторонний контент через <iframe> (рекламу, виджеты, чужие страницы), авторы этого контента могут попытаться украсть данные пользователей, запустить вредоносный скрипт или перенаправить страницу. Атрибут `sandbox` блокирует опасные действия по умолчанию(отвечает за безопасность)

* `allow`
Определяет политику разрешений (Permissions Policy) — какие функции и возможности (например, геолокация, камера, полноэкранный режим, микрофон) разрешено использовать внутри встроенного документа.

Если вы хотите, чтобы встроенное в iframe видео можно было развернуть на весь экран или чтобы сайт внутри iframe мог включить камеру, вы должны это явно разрешить через `allow`


## Важные правила
Используй медиа, на которые у тебя есть права. 
Учитывай размер файлов. 
Внешний сайт может запрещать встраивание(вставку).
