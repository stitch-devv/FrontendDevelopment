# Урок 12 — reduce и сортировка

## Цель урока
Собирать массив в одно значение и сортировать данные корректно.

## Теория и примеры
`reduce` проходит по массиву и накапливает результат:

```javascript
const total = [2, 3, 4].reduce((sum, number) => sum + number, 0)
```

Второй аргумент `0` — начальное значение аккумулятора. 

`sort()` меняет исходный массив. Для чисел указывай функцию сравнения:
```javascript
numbers.sort((a, b) => a - b) // по возрастанию
numbers.sort((a, b) => b - a) // по убыванию
```
Без callback числа могут сортироваться как строки. Для сортировки копии используй `[...numbers].sort(...)`.

## Практика
Посчитай сумму, количество и среднее значение массива. Отсортируй числа по возрастанию и убыванию.
