# Урок 09 — Семантическая структура страницы

## Цель
Разделять страницу на смысловые области.

## Что такое семантика?
Семантика — смысл разметки. Семантический HTML помогает браузерам, поисковым системам и вспомогательным технологиям понимать назначение частей страницы.

## Основные элементы
- `header` — вводная часть страницы или раздела(шапка сайта);
- `nav` — важный блок навигации(например навигация между страницами внутри сайта);
- `main` — основное уникальное содержимое страницы, обычно один видимый `main`;
- `section` — тематический раздел, обычно с заголовком(части сайта);
- `article` — самостоятельное содержимое, например публикация, пост;
- `aside` — дополнительное, косвенно связанное содержимое(реклама, ссылки);
- `footer` — завершающая часть страницы или раздела(подвал сайта);
- `div` — универсальный контейнер без собственного смыслового значения.

## Пример
```html
<body>
  <header>
    <a href="/">Мой сайт</a>
    <nav>
      <a href="/">Главная</a>
      <a href="about.html">Обо мне</a>
    </nav>
  </header>
  <main>
    <section>
      <h1>Портфолио</h1>
      <p>Добро пожаловать.</p>
    </section>
    <section>
      <h2>Проекты</h2>
      <article><h3>Учебный сайт</h3><p>Описание проекта.</p></article>
    </section>
    <aside><h2>Сейчас изучаю</h2><p>HTML.</p></aside>
  </main>
  <footer><p>© 2026 Мой сайт</p></footer>
</body>
```

## Section, article или div?
`section` — тематическая область(частички/блоки сайта); 
`article` — самостоятельная публикация или единица содержимого; 
`div` — нейтральная группировка для оформления или скриптов, если более подходящего элемента нет(используется как контейнер для элементов).

## Ошибки
Использовать `div` для всего; 
применять `section` только ради CSS; 
забывать заголовки;
делать кликабельный `div` вместо `a` или `button`;

## Практика
Перестрой свою страницу в `header`, `nav`, `main`, `section` и `footer`. Добавь два раздела с заголовками.

## Домашнее задание
Сверстай главную страницу блога: шапка, навигация, основной контент, раздел публикаций с двумя `article`, дополнительный блок и подвал.
