# Урок 20 — JSON

## Цель урока
Преобразовывать объекты JavaScript в текстовый формат JSON и обратно.

## Теория и примеры
JSON — текстовый формат обмена данными, часто используемый API.

```javascript
const user = { name: 'Aida', age: 20 }
const jsonText = JSON.stringify(user)
const parsedUser = JSON.parse(jsonText)
```

`JSON.stringify()` который преобразует (сериализует) объекты, массивы или другие значения JavaScript в текстовую строку формата JSON; 
`JSON.parse()` разбирает строку. Если строка не является корректным JSON, `parse` выбросит ошибку.

#### JSON поддерживает объекты, массивы, строки, числа, boolean и `null`. Функции и `undefined` не являются значениями JSON.

## Практика
Преобразуй объект в JSON-строку и обратно. Попробуй разобрать неправильную строку и обработай ошибку.
