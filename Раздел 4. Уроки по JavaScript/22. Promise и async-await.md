# Урок 22 — Promise и async/await

## Цель урока
Понимать асинхронные операции и читать Promise-код.

## Теория и примеры
Promise представляет результат операции, которая завершится позже.

```javascript
fetch('/api/data')
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error(error))
```

`async` позволяет функции возвращать Promise. 
`await` ждёт результат внутри async-функции, не блокируя весь браузер.

```javascript
async function getData() {
    const response = await fetch('/api/data')
    if (!response.ok) throw new Error('Request failed')
    return response.json()
}
```

Для независимых запросов можно использовать `Promise.all()`. Если один запрос зависит от результата другого, выполняй их последовательно.

**Promise.all()** — это статический метод объекта Promise в JavaScript, который позволяет запустить несколько асинхронных операций параллельно и дождаться их общего завершения

## Практика
Создай async-функцию, которая получает данные и возвращает результат. Обработай ошибку через `try/catch`.
