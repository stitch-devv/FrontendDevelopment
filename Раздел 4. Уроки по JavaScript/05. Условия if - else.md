# Урок 05 — Условия if / else

## Цель урока
Выполнять разные действия в зависимости от условия.

## Теория и примеры
```javascript
const score = 82

if (score >= 90) {
    console.log('Отлично')
} else if (score >= 70) {
    console.log('Хорошо')
} else if (score >= 50) {
    console.log('Удовлетворительно')
} else {
    console.log('Нужно повторить тему')
}
```

Условия могут объединять `&&`, `||` и `!`. Не путай `=` (присваивание) и `===/==` (сравнение). 
К falsy-значениям относятся `false`, `0`, `''`, `null`, `undefined` и `NaN`. 
Проверяй пустые строки осознанно.

## Практика
Сделай проверку результата теста с четырьмя диапазонами баллов.

## Домашнее задание
Напиши логику бронирования номера в отеле. Вставь фиксированную сумму за ночь, и правильно рассчитай общую стоимость. Если бронирование идет на 7 и больше дней, рассчитай сумму по скидке. 
Спроси, нужно ли клиенту питание от отеля, если да - добавь деньги за питание в общую стоимость бронирования.
