# Урок 01 — Что такое JavaScript и подключение

## Цель урока
Понять назначение JavaScript и подключить первый скрипт.

## Теория и примеры
*JavaScript* — язык программирования, который может выполняться в браузере и в средах вроде Node.js. В браузере он может реагировать на клики, менять DOM, проверять формы и обращаться к API. 

HTML задаёт структуру, CSS — оформление, JavaScript — поведение.

Подключение внешнего файла:
```html
<script src="script.js" defer></script>
```
`defer` позволяет загружать скрипт параллельно с HTML и выполнить после разбора документа.

```javascript
console.log('Привет, JavaScript!')
```
`console.log()` выводит данные в Console DevTools. 

`alert()` - показывает модальное окно, но в реальных интерфейсах его обычно используют редко.
`prompt()` - вызывает модальное диалоговое окно с полем для ввода текста, а также кнопками «ОК» и «Отмена».
`confirm()` - отображает модальное окно с текстовым вопросом, кнопками «OK» и «Отмена», блокируя взаимодействие со страницей до его закрытия.


#### В Javascript можно решать простые математические вычисления
console.log(5+2)
console.log(6-2)
console.log(3*6)
console.log(15/5)
console.log(3**2)   --> выведение в степень
console.log(11%4)   --> остаток от деления


## Практика
Подключи `script.js`, выведи в Console своё имя, название курса и результат простого вычисления.
