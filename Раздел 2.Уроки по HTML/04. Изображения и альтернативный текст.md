# Урок 04 — Изображения и альтернативный текст

## Цель
Добавлять изображения и писать полезный альтернативный текст.

## Элемент img
```html
<img src="images/profile.jpg" alt="Портрет автора сайта">
```
`src` — путь к файлу; `alt` — текстовая альтернатива; `img` — пустой элемент без закрывающего тега.

## Как писать alt
```html
<img src="team.jpg" alt="Три участника команды работают за ноутбуком">
<img src="decorative-line.png" alt="">
```
Описывай важную информацию изображения в контексте страницы. Для чисто декоративного изображения используй пустой `alt`. Не пропускай атрибут полностью без причины.

## Подпись
```html
<figure>
  <img src="images/workspace.jpg" alt="Рабочее место разработчика">
  <figcaption>Рабочее место для изучения Frontend.</figcaption>
</figure>
```

**'figcaption'** - используется для создания подписи, заголовка или описания к содержимому родительского тега 'figure'

Тег **'figure'** создает контейнер под самостоятельные элементы(фото, иллюстрации, диаграммы)


## Ошибки
Неправильный путь или регистр имени; 
отсутствующий `alt`; 
бессмысленный alt вроде «картинка»; 

## Практика
Создай галерею из трёх изображений, у каждого пропиши `alt`. Одно изображение оберни в `figure` и добавь `figcaption`.
