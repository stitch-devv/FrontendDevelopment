# Урок 03 — Каскад, специфичность и наследование

## Цель урока
Понять, как браузер выбирает итоговый стиль при нескольких правилах.

## Теория и примеры
Если несколько правил подходят элементу, браузер учитывает важность правил, специфичность и порядок объявлений. При равной важности и специфичности обычно побеждает правило, объявленное позже.

```css
p { color: black; }
.note { color: blue; }
p.note { color: darkgreen; }
```

Для `<p class="note">` победит `p.note`, потому что селектор точнее.

Упрощённо: селектор по элементу имеет низкую специфичность, класс/атрибут/псевдокласс — выше, id — ещё выше. 
Не решай каждый конфликт через `!important`: сначала проверь селектор и порядок правил.

**!important — это специальный модификатор в CSS, который повышает приоритет конкретного правила или свойства, заставляя браузер применять именно его**

Некоторые свойства, например `color` и `font-family`, наследуются. `margin` и `border` обычно не наследуются автоматически.

**Наследование в CSS — это механизм, при котором дочерние (вложенные) элементы автоматически перенимают значения определенных CSS-свойств от своих родительских элементов**
