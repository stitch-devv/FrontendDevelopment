# Урок 18 — Формы и пользовательский ввод

## Цель урока
Обрабатывать submit, читать значения полей и показывать ошибки.

## Теория и примеры
```html
<form id="signupForm">
    <label for="email">Email</label>
    <input id="email" name="email" type="email" required>
    <button type="submit">Продолжить</button>
    <p id="message" aria-live="polite"></p>
</form>
```

```javascript
const form = document.querySelector('#signupForm')
const message = document.querySelector('#message')

form.addEventListener('submit', event => {
    event.preventDefault()
    const formData = new FormData(form)
    const email = String(formData.get('email') ?? '').trim()
    if (!email) {
        message.textContent = 'Введите email.'
        return
    }
    message.textContent = `Проверяем адрес: ${email}`
})
```

`preventDefault()` отменяет стандартное действие формы. 
HTML-валидация удобна, но сервер всё равно должен проверять данные. Не выводи пароли в консоль.

## Практика
Создай форму обратной связи с именем, email и сообщением. Проверь пустые поля и покажи ошибки рядом с формой.
