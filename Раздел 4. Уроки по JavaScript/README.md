# Раздел 04. Уроки по JavaScript

## О разделе
JavaScript — язык программирования, который добавляет веб-страницам поведение: реагирует на действия пользователя, меняет DOM, проверяет формы, сохраняет простые данные и получает информацию с сервера.

## Результат обучения
После раздела ты сможешь использовать переменные, типы, операторы, условия, циклы, функции, массивы и объекты; работать с DOM и событиями; проверять формы; пользоваться localStorage, JSON, Fetch API, Promise и async/await; отлаживать ошибки и собрать интерактивный проект.

## Важные правила
- Не вставляй недоверенный текст через `innerHTML`; предпочитай `textContent`.
- Не храни пароли, приватные ключи и секретные токены в `localStorage`.
- Данные из браузера и формы считай непроверенными.
- Клиентская проверка не заменяет серверную проверку.
