# Урок 08 — Отступы, границы, тени и скругления

## Цель урока
Создавать аккуратные карточки и визуально разделять блоки.

## Теория и примеры
```css
.card {
    padding: 24px;
    margin-bottom: 20px;
    border: 1px solid #e5e7eb;
    border-radius: 16px;
    box-shadow: 0 8px 24px rgb(0 0 0 / 8%);
}
```

`padding` создаёт пространство внутри, 

`margin` — пространство снаружи,

margin и padding могут брать 1-4 значений:
1. Одно значение: все 4 стороны;
2. Два значения: верх/вниз(вертикально) по-бокам(горизонтально);
3. Для трёх значений: верх бока низ;
4. Для четырёх значений: верх право низ лево; 
* Если значение будет `0`, можно не указывать рх: margin: 0;

`border-radius` скругляет углы, 
`box-shadow` создаёт тень.

Не добавляй сильные тени и границы каждому элементу чтобы можно было понять структуру.

## Практика
Сделай карточку профиля с отступами, границей, скруглением и мягкой тенью. Сравни вариант с тенью и без неё.

## Домашнее задание
Создай три карточки одного стиля. Используй общие классы, одинаковые отступы и аккуратные границы.
