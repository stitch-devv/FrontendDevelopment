# Урок 14 — Переходы и анимации

## Цель урока
Создавать плавные изменения, не мешающие пользоваться сайтом.

## Теория и примеры
```css
.button {
    background: #222;
    transform: translateY(0);
    transition: background-color 180ms ease, transform 180ms ease;
}
.button:hover {
    background: #444;
    transform: translateY(-2px);
}
```

Для анимации по ключевым кадрам используют `@keyframes`:

```css
@keyframes appear {
    from { opacity: 0; transform: translateY(8px); }
    to { opacity: 1; transform: translateY(0); }
}
.card { animation: appear 400ms ease both; }
```
`appear`  -название нашей анимации. всегда указвый название, она нужна для вызова анимации. Можно называть как угодно

Лучше перечислять конкретные свойства в `transition`, чем автоматически менять `all`.

####
`prefers-reduced-motion` в CSS — это медиафункция, которая позволяет определить, включил ли пользователь в операционной системе/браузере настройку уменьшения или отключения лишней анимации и движений.

**Основные значения**
• *no-preference (значение по умолчанию)* — пользователь спокойно относится к анимации и переходам.
• *reduce* — пользователь попросил уменьшить, свести к минимуму или полностью убрать необязательные анимации, эффекты параллакса и резкие движения.

**Зачем это нужно?**
• Быстрая и неожиданная анимация на экране может вызывать головокружение, тошноту или мигрени у людей с вестибулярными расстройствами и нарушениями.
• Некоторые пользователи просто устают от визуального шума и предпочитают статический или более спокойный интерфейс
