# Урок 04 — Операторы и преобразование типов

## Цель урока
Использовать арифметические, сравнительные и логические операторы.

## Теория и примеры
Арифметика: `+`, `-`, `*`, `/`, `%`, `**`. Сравнения: `>`, `<`, `>=`, `<=`, `===`, `!==`. Обычно используй строгое сравнение.

```javascript
console.log(5 === '5') // false
console.log(5 == '5')  // true: типы преобразуются
```

Логические операторы: `&&` — и, `||` — или, `!` — не.

```javascript
const age = Number('18')
const text = String(25)
const valid = Boolean(1)
```

`Number('abc')` даёт `NaN`. Проверяй пользовательский ввод перед вычислениями.
`NaN` - Not a Number

## Практика
Рассчитай стоимость заказа с количеством и скидкой. Проверь разницу между строгим и нестрогим сравнением.

## Домашнее задание
Сделай расчёт заказа: исходная сумма, скидка и итог. Используй `const`, арифметику и строгие сравнения.
