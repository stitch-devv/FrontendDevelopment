# Урок 21 — Fetch API и HTTP-ответы

## Цель урока
Получать данные с сервера и корректно обрабатывать статус ответа.

## Теория и примеры
`fetch()` отправляет запрос и возвращает Promise, т.е. встроенная глобальная функция, которая позволяет отправлять сетевые (HTTP/HTTPS) запросы на сервер и получать от него данные без перезагрузки страницы

```javascript
async function loadUsers() {
    const response = await fetch('https://jsonplaceholder.typicode.com/users')
    if (!response.ok) {
        throw new Error(`HTTP error: ${response.status}`)
    }
    const users = await response.json()
    console.log(users)
}

loadUsers().catch(error => {
    console.error('Не удалось загрузить пользователей:', error)
})
```

Важная деталь: `fetch()` обычно отклоняет Promise при сетевой ошибке, но HTTP-ответ 404 или 500 сам по себе не вызывает reject. Проверяй `response.ok` или `response.status`.

Для POST-запроса с JSON обычно задают `Content-Type: application/json` и используют `JSON.stringify()` для тела запроса. 
Не отправляй приватные данные неизвестному API.

* POST-запрос в JavaScript — это способ отправить данные на сервер из браузера без перезагрузки страницы (например, при отправке форм, регистрации, добавлении комментариев или загрузке файлов).
Данные в POST-запросе передаются не в адресной строке(URL), а скрыто — в теле запроса (body), и их объем не ограничен.

* GET-запрос в JavaScript — это HTTP-метод запроса, который используется для получения данных с сервера (например, списка товаров, статьи или настроек) без изменения этих данных на сервере
Данные передаются не в адресной строке URL(после знака вопроса "?")
