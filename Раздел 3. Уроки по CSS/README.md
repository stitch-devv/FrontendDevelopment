# Раздел 03. Уроки по CSS

## О разделе
CSS (Cascading Style Sheets) управляет внешним видом HTML: цветами, шрифтами, размерами, отступами, расположением элементов и адаптивностью.

## Результат обучения
После раздела ты сможешь подключать CSS, выбирать элементы селекторами, понимать каскад и Box Model, оформлять текст и фоны, создавать макеты с Flexbox и Grid, использовать псевдоклассы, переходы и media queries, находить ошибки и собирать адаптивный лендинг.

## Уроки
1. Что такое CSS и подключение стилей
2. Селекторы и комбинаторы
3. Каскад, специфичность и наследование
4. Цвета, фон и прозрачность
5. Шрифты и оформление текста
6. Размеры и единицы измерения
7. Box Model
8. Отступы, границы, тени и скругления
9. Display и нормальный поток
10. Position и z-index
11. Flexbox
12. CSS Grid
13. Псевдоклассы и псевдоэлементы
14. Переходы и анимации
15. Адаптивный дизайн
16. Отладка и итоговый проект

## Как проходить
Печатай примеры вручную, меняй значения, проверяй результат в браузере. 
Выполняй практику и домашнее задание перед переходом дальше.

## Итоговый проект
Создай адаптивный лендинг для курса, продукта или портфолио. Нужны шапка, навигация, hero-секция, преимущества, карточки, призыв к действию и подвал. На мобильном экране не должно быть горизонтальной прокрутки.
