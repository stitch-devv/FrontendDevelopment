# Урок 17 — События

## Цель урока
Реагировать на клики, ввод и другие действия пользователя.

## Теория и примеры
```javascript
const button = document.querySelector('#saveButton')
button.addEventListener('click', () => {
    console.log('Кнопка нажата')
})
```

`addEventListener` отделяет логику от HTML и обычно предпочтительнее inline-атрибутов `onclick`.
`addEventListener` позволяет привязать функцию-обработчик к определенному событию на элементе DOM (например, клику мыши, нажатию клавиши на клавиатуре, прокрутке страницы).

Частые события: `click`, `input`, `change`, `submit`, `keydown`, `DOMContentLoaded`. 
Объект события содержит информацию, например `event.target` — элемент, с которым связано событие.

```javascript
input.addEventListener('input', event => {
    console.log(event.target.value)
})
```
