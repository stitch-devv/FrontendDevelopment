# Урок 01 — Что такое CSS и подключение стилей

## Цель урока
Понять назначение CSS, синтаксис правила и способы подключения.

## Теория и примеры
CSS задаёт внешний вид HTML. HTML отвечает за структуру, CSS — за оформление, JavaScript — за поведение.

```css
селектор {
    свойство: значение;
}

h1 {
    color: navy;
    font-size: 36px;
}
```

`h1` — селектор, `color` — свойство, `navy` — значение. Объявления разделяются точкой с запятой(внимательно следите за ; в конце объявлений).

Чтобы задавать стили, нужен базовый английский, ведь свойства на английском:
задний фон → background-color
длина → width
высота → height
размер шрифта → font-size

* ВАЖНО: если свойство состоит из двух или более слов, писать надо через дефис(-)

Подключай внешний файл внутри `head`:
```html
<link rel="stylesheet" href="style.css">
```
Можно оформлять сайт и внутри html файла через внутренний тег `<style>`, но отдельный CSS-файл удобнее поддерживать. 
Inline-стили в атрибуте `style` не стоит использовать как основной способ оформления.

Комментарий: `/* заметка для разработчика */`.

## Практика
Создай HTML-страницу с заголовком, абзацем и кнопкой. Подключи `style.css`, измени цвет заголовка, размер текста и фон.
