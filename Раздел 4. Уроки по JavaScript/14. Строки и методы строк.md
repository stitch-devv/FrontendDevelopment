# Урок 14 — Строки и методы строк

## Цель урока
Очищать и проверять текст, формировать сообщения.

## Теория и примеры
```javascript
const text = '  Frontend Course  '
text.trim()
text.toLowerCase()
text.toUpperCase()
text.includes('Course')
text.replace('Course', 'Class')
text.slice(0, 8)
```

Строки неизменяемы: методы возвращают новую строку. 
`trim()` убирает пробелы по краям, 
`toLowerCase()` приводит к нижнему регистру. 
`toUpperCase()` преобразует все символы в строке в верхний регистр.
`includes()` проверяет, содержит ли массив определенный элемент или строка определенную подстроку, и возвращает логическое значение true или false.
`replace()` ищет в строке указанный шаблон (подстроку или выражение) и заменяет его на новое значение.
`slice()` встроенная функция, которая используется для получения части массива или строки, не изменяя при этом оригинал.


Шаблонные строки используют обратные кавычки:

```javascript
const name = 'Aida'
const message = `Привет, ${name}!`
```

`trim()` полезен для проверки поля, но не удаляй внутренние пробелы в именах или сообщениях без причины.

## Практика
Очисти строку через `trim`, приведи к нижнему регистру и проверь наличие слова.
