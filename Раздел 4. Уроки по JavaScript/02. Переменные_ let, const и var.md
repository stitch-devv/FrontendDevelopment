# Урок 02 — Переменные: let, const и var

## Цель урока
Хранить значения и выбирать подходящее объявление переменной.

## Теория и примеры
```javascript
const userName = 'Aida'
let score = 0
score = score + 10
console.log(userName, score)
```

*const, var, let* - переменные; они нужны для хранения данных(информации)
С сохраненными данными можно взаимодействовать

`const` запрещает повторное присваивание переменной; `let` разрешает. 
По умолчанию выбирай `const`, если не собираешься переназначать значение.
`var` — старый способ переменной(действует как `const`), в современном коде обычно используют `let` и `const`.

**`score = score + 10` - добавляет к 0(let score = 0) 10, сохраняет результат и выводит в консоль**

Имена должны описывать смысл: `userAge`, `totalPrice`, `isLoggedIn`. 
JavaScript чувствителен к регистру: `userName` и `username` — разные переменные.

## Практика
Создай переменные для имени, возраста, страны и очков. Измени очки через `let`, затем выведи значения.
