# Урок 06 — switch

## Цель урока
Выбирать один вариант из нескольких конкретных значений.

## Теория и примеры
```javascript
const language = 'en'

switch (language) {
    case 'ru':
        console.log('Привет')
        break
    case 'en':
        console.log('Hello')
        break
    case 'ky':
        console.log('Салам')
        break
    default:
        console.log('Unknown language')
}
```

`break` завершает ветку(объязательна для корректной работы условия). Без него выполнение может продолжиться в следующую ветку. 
`default` срабатывает, если совпадения нет(считай как "else"). 
Для диапазонов и сложных условий чаще удобнее `if/else`.
`switch/case` удобнее использовать при работе с текстом

## Практика
Создай switch для выбора языка интерфейса: ru, en, ky. Для неизвестного языка выводи значение по умолчанию.
