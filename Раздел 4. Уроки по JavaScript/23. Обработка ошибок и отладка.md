# Урок 23 — Обработка ошибок и отладка

## Цель урока
Читать сообщения об ошибках и исправлять проблемы системно.

## Теория и примеры
Ошибки бывают синтаксическими, ошибками выполнения и логическими.

```javascript
try {
    const data = JSON.parse('не JSON')
    console.log(data)
} catch (error) {
    console.error('Неправильный формат данных')
}
```

Не оставляй пустой `catch`: это скрывает проблему. Показывай пользователю понятное сообщение, а технические сведения используй для отладки.

В DevTools: 
- Console — ошибки и вывод; 
- Sources — breakpoint; 
- Network — запросы; 
- Elements — DOM. 

Прочитай первую ошибку, найди строку, проверь значения.

## Практика
Создай намеренную ошибку, найди её в Console, поставь breakpoint, посмотри значения и исправь код.
