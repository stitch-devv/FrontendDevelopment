# Урок 11 — map, filter, find, some, every

## Цель урока
Преобразовывать массивы и искать элементы.

## Теория и примеры
`map` создаёт новый массив преобразованных значений:
```javascript
const doubled = [1, 2, 3].map(n => n * 2)
```

`filter` оставляет элементы, для которых условие истинно:
```javascript
const adults = users.filter(user => user.age >= 18)
```
В `filter` callback должен возвращать условие.


`find` возвращает первый подходящий элемент или `undefined`. 
`some` проверяет, подходит ли хотя бы один элемент, `every` — подходят ли все.

```javascript
const user = users.find(user => user.id === 2)
const hasFree = prices.some(price => price === 0)
const allPositive = numbers.every(number => number > 0)
```

Эти методы обычно не меняют исходный массив. 

## Практика
Для массива товаров получи названия через `map`, товары дешевле заданной цены через `filter`, найди товар по id.
