# Урок 02 — Заголовки, абзацы и текстовые элементы

## Цель
Структурировать текст и выбирать элементы по смыслу, а не ради внешнего вида.

## Заголовки
```html
<h1>Главная тема</h1>
<h2>Раздел</h2>
<h3>Подраздел</h3>
```
Есть шесть уровней: `h1`–`h6`. Обычно на странице один основной `h1`, разделы отмечаются `h2`, подразделы — `h3`. Размер заголовка позже настраивается CSS.

**`h1` в сайте создается только один раз, а начиная с `h2` можно по несколько раз открывать их**

## Абзацы и переносы
```html
<p>Первый абзац.</p>
<p>Второй абзац.</p>
<p>Улица Примерная, 10<br>Бишкек</p>
<hr>
```
`p` — абзац, `br` — перенос строки внутри содержимого(переносит следующий после себя элемент на новую строку), `hr` — тематический разделитель(линия). Не используй много `br` для отступов: для оформления есть CSS.

## Смысловое выделение
```html
<p><strong>Важно:</strong> сохрани файл.</p>
<p>Это <em>особенно важно</em>.</p>
<p>Цена: <del>2000</del> 1500 сом.</p>
<p><mark>Обрати внимание</mark> на срок.</p>
<p>H<sub>2</sub>O; 2<sup>2</sup></p>
```
`strong` обозначает важность, `em` — смысловое ударение, `del` — удалённый текст(зачеркнутый), `mark` — выделенный фрагмент(маркер), `sub` и `sup` — нижний и верхний индексы.


## Ошибки
Не выбирай заголовок только по размеру; 
не делай большие отступы через `br`; 
не превращай всю страницу в один абзац.

Создай статью «Почему я изучаю Frontend»: используй `h1`, три `h2`, минимум пять абзацев, `strong`, `em`, `hr` и пример кода.
