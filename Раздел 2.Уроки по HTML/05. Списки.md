# Урок 05 — Списки

## Цель
Создавать маркированные, нумерованные и описательные списки.

## Маркированный список
```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```
Используй `ul`, если порядок пунктов не важен. `li` — отдельный элемент списка.

## Нумерованный список
```html
<ol>
  <li>Создать папку.</li>
  <li>Создать HTML-файл.</li>
  <li>Открыть его в браузере.</li>
</ol>
```
`ol` подходит для последовательности шагов. Можно задать `start="3"`, если нумерация должна начинаться с другого числа.

## Описательный список
```html
<dl>
  <dt>HTML</dt>
  <dd>Задаёт структуру страницы.</dd>
  <dt>CSS</dt>
  <dd>Описывает оформление страницы.</dd>
</dl>
```
`dt` — термин, `dd` — описание.


## Ошибки
`li` вне списка; 
нумерованный список там, где порядок не важен; 
список используется только ради визуального эффекта.

## Практика
Создай «Мои навыки» через `ul`, «План обучения» через `ol` и словарь из трёх терминов через `dl`.
