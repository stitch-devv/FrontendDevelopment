# Урок 07 — Box Model

## Цель урока
Понять состав коробки элемента и расчёт его размеров.

## Теория и примеры
Каждый элемент можно представить как коробку: content (содержимое), padding (внутренний отступ), border (граница), margin (внешний отступ).

```css
.box {
    width: 300px;
    padding: 20px;
    border: 2px solid #333;
    margin: 16px;
}
```
---

#### Запомни! border: ; всегда берет три значения: ширина рамки, тип рамки и ее цвет.

*Типы рамки в CSS:* 
• none — рамка отсутствует (значение по умолчанию).
• hidden — рамка скрыта (похоже на none, но влияет на схлопывание границ в таблицах).
• solid — сплошная прямая линия (самый популярный вариант).
• dotted — рамка состоит из точек.
• dashed — пунктирная рамка из коротких черточек.
• double — двойная сплошная линия.

*Объёмные 3D-рамки (зависят от цвета фона и самого элемента)*

• groove — рамка выглядит как вдавленный желоб.
• ridge — рамка выглядит как выпуклый гребень (инверсия groove).
• inset — рамка делает весь блок визуально вдавленным внутрь.
• outset — рамка делает весь блок визуально выпуклым наружу.

---

При `content-box` заданная ширина относится к содержимому, а padding и border добавляются сверху. Часто удобнее:

```css
* {
    box-sizing: border-box;
}
```

При `border-box` заданная ширина включает content, padding и border. `margin` находится снаружи.

## Практика
Создай два блока с одинаковым `width`, но разными `box-sizing`. Сравни размеры, затем включи `border-box` для всех элементов.

## Домашнее задание
Сверстай три карточки одинаковой ширины. Используй `box-sizing: border-box`, padding, border и margin. Проверь, что они не выходят за контейнер.
