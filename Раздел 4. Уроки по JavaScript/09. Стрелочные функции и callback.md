# Урок 09 — Стрелочные функции и callback

## Цель урока
Использовать стрелочный синтаксис и передавать функции как значения.

## Теория и примеры
```javascript
const sum = (a, b) => a + b
const double = number => number * 2
const greet = name => `Привет, ${name}`
```

Если тело состоит из одного выражения, фигурные скобки и `return` можно опустить. 
Для возврата объекта-литерала оберни его в скобки: `const makeUser = name => ({ name })`.

*Объект-литерал в JavaScript* — это способ создания и инициализации объекта с помощью фиксированного набора пар **«ключ: значение»**, заключенного в фигурные скобки


*Callback-функция(функция обратного вызова)* — это функция, которую передают в качестве аргумента в другую функцию, чтобы та выполнила её позже:

```javascript
[1, 2, 3].forEach(number => {
    console.log(number)
})
```
`forEach()` — это встроенный метод массива, который выполняет указанную функцию один раз для каждого элемента в массиве

Стрелочные функции не имеют собственного `this`, поэтому они не являются полной заменой обычным функциям во всех ситуациях.
