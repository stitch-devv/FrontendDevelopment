# Урок 12 — CSS Grid

## Цель урока
Создавать макеты из строк и колонок.

## Теория и примеры
```css
.cards {
    display: grid;
    grid-template-columns: repeat(3, minmax(0, 1fr));
    gap: 20px;
}
```

`grid-template-columns` задаёт колонки(горизонтально), 
`grid-template-crows` задаёт количество колонки(ряды; вертикально),
`fr` делит доступное пространство, 
`gap` задаёт промежутки(расстояние; отступы); 


Для адаптивной сетки:

```css
.cards {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
    gap: 20px;
}
```

`minmax()` задаёт нижнюю и верхнюю границы размера дорожки.
#### Flexbox чаще удобнее для одной оси, Grid — для двумерной сетки; их можно сочетать.

## Практика
Создай сетку из шести карточек: сначала две колонки, затем три, затем `auto-fit` с `minmax()`.

## Домашнее задание
Сделай секцию проектов, где карточки перестраиваются под ширину контейнера и не создают лишнюю горизонтальную прокрутку.
