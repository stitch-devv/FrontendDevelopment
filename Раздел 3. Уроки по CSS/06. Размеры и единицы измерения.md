# Урок 06 — Размеры и единицы измерения

## Цель урока
Разобраться в px, %, rem, em, vw/vh и гибких размерах.

## Теория и примеры
- `px` — CSS-пиксель, абсолютная единица измерения; 
- `%` — часто относительно размера родителя;
- `rem` — это относительная единица измерения, которая равна размеру шрифта корневого элемента документа (тега <html>); *1rem=16px*
- `em` — относительная единица измерения, которая равна текущему размеру шрифта (font-size) самого элемента или его родителя; 
**Пример: Если у родительского блока задан font-size: 16px, то 1em внутри него равен 16px**
- `vw` / `vh` — доли ширины и высоты окна просмотра.

```css
.container { width: 90%; max-width: 1100px; margin-inline: auto; }
.hero { min-height: 60vh; }
h1 { font-size: clamp(2rem, 5vw, 4rem); }
```

*clamp() в CSS* — это встроенная математическая функция, которая ограничивает значение в заданном диапазоне. Всегда берет три значения
Не задавай фиксированную высоту всем блокам: текст может быть длиннее ожидаемого. `clamp(min, preferred, max)` позволяет ограничить гибкий размер.

## Практика
Создай контейнер шириной 90% с `max-width`. Сделай заголовок через `clamp()` и проверь на узком и широком экране.
