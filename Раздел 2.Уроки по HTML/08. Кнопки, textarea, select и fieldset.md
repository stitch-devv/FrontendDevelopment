# Урок 08 — Кнопки, textarea, select и fieldset

## Цель
Использовать дополнительные элементы форм.

## Кнопки
```html
<button type="button">Обычная кнопка</button>
<button type="submit">Отправить</button>
<button type="reset">Сбросить</button>
```
`button` запускает действие, часто через JavaScript; 
`submit` отправляет форму; 
`reset` сбрасывает поля. 

#### Внутри формы указывай `type` явно, чтобы избежать неожиданной отправки.

## Многострочный текст
```html
<label for="message">Сообщение</label>
<textarea id="message" name="message" rows="5" placeholder="Напиши сообщение"></textarea>
```
`textarea` подходит для длинного текста. Его содержимое находится между тегами, а не в атрибуте `value`.
`rows="5"` дает высоту к текстовой поле

## Выпадающий список
```html
<label for="course">Выбери курс</label>
<select id="course" name="course" required>
  <option value="">Выбери вариант</option>
  <option value="html">HTML</option>
  <option value="css">CSS</option>
</select>
```
`select` - создание выпадающего списка, `option` — вариант списка, `value` — значение, отправляемое формой.

## Группа полей
```html
<fieldset>
  <legend>Формат обучения</legend>
  <label><input type="radio" name="format" value="online"> Онлайн</label>
  <label><input type="radio" name="format" value="offline"> Очно</label>
</fieldset>
```
`fieldset` группирует связанные поля, `legend` даёт группе название.

## Практика
Создай форму обратной связи: имя, тема через `select`, сообщение через `textarea`, способ ответа(по звонку, сообщение) через radio и кнопку отправки.

## Домашнее задание
Сделай опрос студентов: курс, несколько технологий через checkbox, уровень через radio, textarea и submit. Все поля должны иметь понятные подписи.

## Проверка
