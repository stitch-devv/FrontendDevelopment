# Урок 01 — Основы HTML и структура документа

## Цель
Понять, что такое HTML, чем тег отличается от элемента и как устроен документ.

## 1. Что такое HTML?
HTML (HyperText Markup Language) — язык разметки, который задаёт структуру и смысл содержимого: заголовки, абзацы, ссылки, изображения, формы. **Это НЕ язык программирования** общего назначения. **CSS оформляет страницу, JavaScript добавляет поведение.**

Язык разметки ≠ язык программирование
Язык разметки это НЕ язык программирования

## 2. Тег и элемент
```html
<p>Это абзац.</p>
```
`<p>` — открывающий тег, `</p>` — закрывающий, текст — содержимое, весь фрагмент — элемент. Пустые элементы не имеют закрывающего тега: например, `img`, `br`, `hr`, `input`, `meta`, `link`.

## 3. Структура документа
```html
<!doctype html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Моя первая страница</title>
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это моя первая HTML-страница.</p>
</body>
</html>
```
`doctype` включает современный режим отображения; `html` — корневой элемент; `lang` задаёт язык документа; `head` содержит метаданные и подключения; `charset` задаёт кодировку; `viewport` помогает корректно отображать страницу на мобильных устройствах; `title` задаёт название вкладки; `body` содержит содержимое страницы.

## 4. Вложенность
```html
<section>
  <h2>Обо мне</h2>
  <p>Изучаю <strong>Frontend</strong>.</p>
</section>
```
Закрывай элементы в обратном порядке их открытия. Неправильно: `<p><strong>Текст</p></strong>`. Правильно: `<p><strong>Текст</strong></p>`.

## 5. Комментарии
```html
<!-- Комментарий для разработчика -->
```
Комментарий не отображается как обычный текст страницы. Не храни в нём пароли или ключи: исходный HTML доступен посетителям.

Комментарий используется для записей и заметок :)

Чтобы создать комментарий, нажми на сочетание клавиш CTRL + /
Если еще раз нажмешь на эти же клавиши, комментарий отключиться

## Частые ошибки
- забыли `doctype`, `lang` или `charset`;
- перепутали `head` и `body`;
- неправильно вложили элементы;
- сохранили файл как `.txt`, а не `.html`.

#### а лучше, используй готовый шаблон для открытия html структуру. Для этого, в html-файле поставь ! и нажми "Enter" на клавиатуре для ввода. Появиться точно такая же структура документа, что писали выше(3.структура документа)
