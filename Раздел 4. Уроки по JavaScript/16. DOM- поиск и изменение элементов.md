# Урок 16 — DOM: поиск и изменение элементов

## Цель урока
Находить HTML-элементы и менять содержимое через JavaScript.

## Теория и примеры
DOM — объектное представление HTML-документа.

```html
<h1 id="title">Привет</h1>
<p class="description">Описание</p>
```

```javascript
const title = document.querySelector('#title')
const description = document.querySelector('.description')
title.textContent = 'Новый заголовок'
description.classList.add('highlight')
```

`querySelector` возвращает первый элемент или `null`; `querySelectorAll` — коллекцию. 
Проверяй, что элемент найден, прежде чем обращаться к его свойствам.

Для пользовательского текста предпочитай `textContent`.

`innerHTML` — это встроенное свойство DOM-элемента в JavaScript, которое позволяет читать или изменять HTML-содержимое внутри этого элемента в виде обычной строки
`innerText` — это свойство DOM-элемента, которое позволяет получать или изменять текстовое содержимое этого элемента и всех его дочерних узлов
