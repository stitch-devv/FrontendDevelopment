# Урок 19 — localStorage и sessionStorage

## Цель урока
Сохранять простые данные в браузере.

## Теория и примеры
`localStorage` хранит данные между сессиями до удаления; 
`sessionStorage` обычно ограничен текущей вкладкой/сессией. 
Оба хранилища сохраняют строки.

```javascript
localStorage.setItem('theme', 'dark')
const theme = localStorage.getItem('theme')
localStorage.removeItem('theme')
```

Для объектов используй JSON:

```javascript
const settings = { theme: 'dark', fontSize: 16 }
localStorage.setItem('settings', JSON.stringify(settings))
const saved = localStorage.getItem('settings')
const parsed = saved ? JSON.parse(saved) : null
```

Не храни пароли, приватные ключи и чувствительные токены в localStorage.

## Практика
Сделай переключатель темы и сохраняй выбор в localStorage. После перезагрузки тема должна восстанавливаться.
