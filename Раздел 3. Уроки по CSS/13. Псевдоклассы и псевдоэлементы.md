# Урок 13 — Псевдоклассы и псевдоэлементы

## Цель урока
Оформлять состояния элементов и отдельные части содержимого.

## Теория и примеры
Псевдокласс выбирает элемент в определённом состоянии или положении:

```css
a:hover { color: darkblue; }
button:focus-visible { outline: 3px solid orange; }
li:first-child { font-weight: bold; }
input:disabled { opacity: 0.5; }
```

Псевдоэлемент оформляет часть элемента или создаёт декоративное содержимое:

```css
.note::before {
    content: "Важно: ";
    font-weight: bold;
}
p::first-letter { font-size: 2em; }
```

Не убирай видимый фокус без замены: пользователям клавиатуры важно видеть активный элемент. 
Не помещай важный смысл только в `content`.

## Практика
Оформи кнопку в состояниях hover, focus-visible, active и disabled. 
Добавь декоративный маркер через `::before`.
