# Урок 13 — Объекты

## Цель урока
Хранить связанные данные в свойствах объекта.

## Теория и примеры
```javascript
const user = {
    name: 'Aida',
    age: 20,
    isStudent: true,
    greet() {
        return `Привет, я ${this.name}`
    }
}
```
Доступ к свойствам: `user.name` или `user['age']`. 
Квадратные скобки удобны, когда ключ находится в переменной. 
Свойства можно менять и добавлять: `user.age = 21`, `user.city = 'Bishkek'`.

`this` зависит от способа вызова. В `user.greet()` он указывает на объект перед точкой. 
Стрелочная функция не создаёт собственный `this`.

## Практика
Создай объект товара с названием, ценой, категорией и наличием. Измени цену, наличие и выведи значения.

## Домашнее задание
Создай массив объектов студентов. Найди студента по id, измени статус и посчитай средний балл.
