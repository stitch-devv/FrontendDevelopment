# Урок 06 — Таблицы

## Цель
Показывать связанные данные в таблице и правильно размечать заголовки.

## Основы
```html
<table>
  <tr><th>Технология</th><th>Назначение</th></tr>
  <tr><td>HTML</td><td>Структура</td></tr>
  <tr><td>CSS</td><td>Оформление</td></tr>
</table>
```
`table` — таблица, `tr` — строка(горизонтально), `th` — ячейка-заголовок, `td` — обычная ячейка(вертикально)

## Структура и подпись
```html
<table>
  <caption>План обучения</caption>
  <thead>
    <tr><th scope="col">Раздел</th><th scope="col">Статус</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML</td><td>В процессе</td></tr>
  </tbody>
</table>
```
`thead` — заголовочная часть, `tbody` — основные строки, `tfoot` — итоговая часть при необходимости, `caption` — название таблицы. `scope="col"` связывает заголовок со столбцом, `scope="row"` — со строкой.

## Объединение ячеек
`colspan="2"` объединяет ячейки по горизонтали, `rowspan="2"` — по вертикали. Используй их только если этого требует структура данных.

## Когда таблица не подходит
Таблицы нужны для табличных данных: расписаний, сравнений, отчётов. Не используй их для всей структуры страницы или отступов — для макета есть CSS.

## Ошибки
Нет `tr` вокруг ячеек;
заголовки сделаны обычными `td`;
отсутствуют понятные заголовки; 
таблица используется для макета;

## Практика
Создай расписание с колонками «День», «Тема», «Статус». Добавь `caption`, `thead`, `tbody` и `th`.

## Домашнее задание
Сделай таблицу сравнения трёх технологий: минимум три столбца, четыре строки данных и понятные заголовки.

## Проверка
Чем отличаются `th` и `td`? Для чего нужны `caption` и `scope`?
