# Урок 08 — Функции

## Цель урока
Создавать повторно используемые блоки кода с параметрами и результатом.

## Теория и примеры
```javascript
function greet(name) {
    return `Привет, ${name}!`
}

function calculateTotal(price, quantity) {
    return price * quantity
}
```

Параметры получают значения при вызове. 
`return` возвращает результат и завершает функцию. Если функция ничего явно не возвращает, результат — `undefined`.

Старайся, чтобы функция решала одну понятную задачу. Имена обычно описывают действие: `calculateTotal`, `formatName`, `isAdult`.


• *Function Declaration (Объявление функции)*
Создается с помощью ключевого слова function, имеет имя и поддерживаемое всплытие (hoisting) — ее можно вызвать до строки объявления в коде.
```javascript
function sayHi() {
  console.log("Привет!");
}
```

• *Function Expression (Функциональное выражение)*
Функция создается внутри выражения (обычно присваивается переменной или константе). 
Bызов до строки создания приведет к ошибке.
```javascript
const sayHi = function() {
  console.log("Привет!");
};
```

• *Стрелочные функции (Arrow Functions, ES6)*
Более короткая запись через синтаксис =>. Не имеют собственного контекста и объекта
```javascript
const sayHi = () => {
  console.log("Привет!");
};
```
