# Урок 04 — Цвета, фон и прозрачность

## Цель урока
Задавать цвет текста, фона и фоновые изображения.

## Теория и примеры
Цвет можно записать именем, HEX, RGB или HSL:

```css
.title { color: navy; }
.card { background-color: #f3f4f6; }
.button { background-color: rgb(30 64 175); }
.accent { color: hsl(145 60% 30%); }
```

Фоновое изображение:
```css
.hero {
    background-image: url("images/cover.jpg");
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}
```

`cover` заполняет область и может обрезать часть изображения; 
`contain` показывает всё изображение, но могут остаться пустые области. 
`opacity` влияет на весь элемент и его содержимое. 
Если нужна прозрачность только фона, используй цвет с альфа-каналом: `rgb(0 0 0 / 50%)`.

Проверяй контраст: текст должен оставаться читаемым.

## Практика
Создай hero-блок с цветным фоном, текстом и кнопкой. Попробуй HEX и HSL. 
При наличии изображения настрой `cover` и `background-position`.

## Домашнее задание
Составь палитру из пяти цветов: основной, дополнительный, акцентный, фон и цвет текста. Применяй её последовательно и проверь читаемость.
