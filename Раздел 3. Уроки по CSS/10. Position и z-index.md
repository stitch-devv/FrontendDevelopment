# Урок 10 — Position и z-index

## Цель урока
Понимать разные способы позиционирования элементов.

## Теория и примеры
```css
.static { position: static; }
.relative { position: relative; }
.absolute { position: absolute; }
.fixed { position: fixed; }
.sticky { position: sticky; top: 0; }
```

`static` — стандартное положение. 
`relative` сохраняет место в потоке. 
`absolute` выводит элемент из обычного потока и дает свободную позицию(абсолютная позиция). 
`fixed` обычно привязан к окну просмотра(фиксированная позиция). 
`sticky` становится липким при прокрутке.

```css
.card { position: relative; }
.badge { position: absolute; top: 12px; right: 12px; }
```

`z-index` управляет наложением в рамках контекстов наложения(слои в сайте). Он не решает все проблемы слоёв автоматически.
Если `z-index` принимает негативное значение(меньше 0; -), элемент двигается в задние слои.
Если `z-index` принимает позитивное значение(больше 0), элемент двигается в передние слои.
Если `z-index` принимает стандартное значение(0), элемент находится в основном слое. 

## Практика
Создай карточку с бейджем «Новинка» в правом верхнем углу через `position: relative` и `absolute`.
