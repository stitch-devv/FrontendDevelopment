# Урок 03 — Типы данных

## Цель урока
Познакомиться с основными типами JavaScript.

## Теория и примеры
```javascript
const name = 'John'       // string
const age = 24             // number
const isStudent = false      // boolean
const emptyValue = null
let notAssigned             // undefined
const user = { name: 'Aida' } // object
const skills = ['HTML', 'CSS'] // array (вид объекта)
```

*Тип данных в js*
1. number (Число) — целые числа и числа с плавающей точкой(а также специальные числовые значения: Infinity, -Infinity, NaN).
2. string (Строка) — последовательность символов в одинарных, двойных или обратных кавычках ('', "",``).
3. boolean (Булевый/логический тип) — имеет всего два значения: true(истина; правда) и false (ложь).
4. null — специальное значение, означающее «ничего», «пусто» или «значение неизвестно».
5. undefined — значение для переменной, которой еще не присвоили значение.
6. symbol (Символ) — уникальный и неизменяемый идентификатор, который часто используют для создания скрытых свойств объектов.
7. object (Объект) — используется для хранения коллекций данных и более сложных сущностей ({} — обычные объекты, массивы [], функции function, даты и т.д.).
    * Примечание: Функции технически являются объектами, но оператор typeof возвращает для них строку "function"

```javascript
console.log(typeof 'hello') // "string"
console.log(typeof 42)      // "number"
console.log(typeof true)    // "boolean"
```

Особенность: `typeof null` возвращает `"object"` по исторической ошибке. Проверяй null через `value === null`.

## Сравнение в js
• == (нестрогое равенство): Сравнивает только значения (например, '5' == 5 даст true).
• === (строгое равенство): Сравнивает и значение, и тип данных. Если типы разные, вернет false (например, '5' === 5 даст false). **Рекомендуется использовать всегда по умолчанию.**
• != и !== (неравенство): Противоположности операторов == и ===. **! === "НЕ"**
• > - больше
• < - меньше
• >= больше или равно
• <= меньше или равно

#### Числа записанные в `prompt()` передают тип данных 'string'. Если тебе нужно взять число в типе 'number', перемести `prompt()` внутрь parseInt()
