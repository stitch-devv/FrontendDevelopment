# Урок 11 — Flexbox

## Цель урока
Распределять элементы в одном измерении — строке или колонке.

## Теория и примеры
```css
.nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
    gap: 16px;
}
```

`flex-direction` задаёт направление; 
`justify-content` распределяет элементы по главной оси(горизонтально); 
`align-items` выравнивает по поперечной(вертикально); 
`gap` задаёт расстояние; 
`flex-wrap: wrap` разрешает перенос элементов; 
#### Главная ось меняется, если задать `flex-direction: column`.

## Практика
Сделай шапку с логотипом, навигацией и кнопкой. Используй Flexbox, `gap`, `justify-content` и `align-items`; затем измени направление.
