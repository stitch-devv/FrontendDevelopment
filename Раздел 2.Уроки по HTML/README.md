# Раздел 02. Уроки по HTML

HTML задаёт структуру и смысловое содержание страницы. CSS отвечает за оформление, JavaScript — за поведение.

## Результат
После раздела ты сможешь создавать HTML-документы, размечать текст, добавлять ссылки, изображения, списки, таблицы, формы и медиа, использовать семантические элементы, заполнять метаданные и проверять разметку.

## Как проходить
1. Иди по урокам по порядку.
2. Набирай код вручную и проверяй в браузере.
3. Выполняй практику и домашнее задание без копирования готового решения.
4. В конце собери итоговый проект.

## Уроки
1. Основы HTML и структура документа
2. Заголовки, абзацы и текстовые элементы
3. Ссылки и пути к файлам
4. Изображения и альтернативный текст
5. Списки
6. Таблицы
7. Формы и input
8. Кнопки, textarea, select и fieldset
9. Семантическая структура страницы
10. Атрибуты, class и id
11. Аудио, видео и iframe
12. Head, метаданные и базовый SEO
13. Доступность, валидность и отладка
14. Итоговый проект — сайт-портфолио

## Итоговый проект
Сделай сайт минимум из двух страниц: `index.html` и `contact.html`. Добавь навигацию, заголовки, абзацы, изображение с `alt`, список навыков, проекты, форму обратной связи, семантические элементы и корректные метаданные.
