# Урок 15 — Область видимости и замыкания

## Цель урока
Понять доступность переменных и базовую идею замыкания.

## Теория и примеры
```javascript
const siteName = 'Course'

function showName() {
    const localName = 'Student'
    console.log(siteName, localName)
}
```

Переменная, объявленная внутри функции, недоступна снаружи(в нашем случае localName). 
`let` и `const` имеют блочную область видимости.

Замыкание возникает, когда функция сохраняет доступ к переменным внешней области:

```javascript
function createCounter() {
    let count = 0
    return function () {
        count += 1
        return count
    }
}
const counter = createCounter()
console.log(counter()) // 1
console.log(counter()) // 2
```

Внутренняя функция продолжает использовать `count`, хотя внешняя функция уже завершилась.

## Практика
Проверь область видимости переменных внутри блока и создай функцию-счётчик через замыкание.
