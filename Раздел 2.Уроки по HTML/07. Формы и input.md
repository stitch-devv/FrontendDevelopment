# Урок 07 — Формы и input

## Цель
Понять, как форма собирает данные и какие типы полей использовать.

## Form
```html
<form action="/register" method="post">
  <!-- Поля формы -->
  <button type="submit">Зарегистрироваться</button>
</form>
```
`action` задаёт адрес обработки (адрес, куда отправляются введенные пользователем данные после нажатия кнопки «Отправить»); 
`method="get"` обычно подходит для поиска и фильтров (Все введенные пользователем в форме поля и их значения прикрепляются к адресной строке после знака вопроса ? в виде пар ключ=значение, разделенных амперсандом &), 
`method="post"` часто используют для отправки или изменения данных(отправляет данные скрыто внутри http-тела. Это и отличие от `method="get"`)

Если сервер не настроен, форма не выполнит настоящую регистрацию.

## Label, id и name
```html
<label for="email">Электронная почта</label>
<input type="email" id="email" name="email" placeholder="name@example.com" required>
```

`for` должен совпадать с `id` (сязывает текстовой подпись с конкретным элементом формы);
`name` используется как имя поля при отправке;
`placeholder` показывает пример, но не заменяет label;


## Типы input
```html
<input type="text" name="name">
<input type="email" name="email">
<input type="password" name="password">
<input type="number" name="age">
<input type="tel" name="phone">
<input type="url" name="website">
<input type="search" name="query">
<input type="date" name="birthday">
<input type="checkbox" name="agree">
<input type="radio" name="level" value="beginner">
<input type="file" name="document">
```
Тип помогает браузеру подобрать интерфейс и базовую проверку

## Ограничения
```html
<input type="email" name="email" required>
<input type="number" name="age" min="13" max="120">
<input type="password" name="password" minlength="8" required>
```
`required`, `min`, `max`, `minlength`, `maxlength`, `pattern`, `autocomplete` помогают задать требования. Клиентская проверка не заменяет серверную.

1. `required` атрибут, который делает поле обязательным для заполнения;
2. `pattern` — это атрибут тега <input>, который проверяет правильность введенных пользователем данных перед отправкой формы;
3. Атрибут `autocomplete` включает или отключает функцию автозаполнения полей формы браузером;
4. Атрибут `min` — это специальный параметр для <input>, который задает МИНИМАЛЬНО ДОПУСТИМОЕ ЗНАЧЕНИЕ для поля ввода(в нашем примере, тебе должно быть больше 13 лет);
5. Атрибут `max` — это специальный параметр для <input>, который задает МАКСИМАЛЬНО ДОПУСТИМОЕ ЗНАЧЕНИЕ для поля ввода(в нашем примере, тебе должно быть меньше 120 лет);
6. `maxlength` — это инструмент, который задает МАКСИМАЛЬНОЕ КОЛИЧЕСТВО СИМВОЛОВ, которое пользователь может ввести в поле ввода;
6. `minlength` — это инструмент, который задает МИНИМАЛЬНОЕ КОЛИЧЕСТВО СИМВОЛОВ, которое пользователь может ввести в поле ввода(в нашем примере, длина пароля должна быть больше 8 символов);

## Checkbox и radio

Radio` — выбор одного варианта из группы.

## Безопасность
Не собирай настоящие пароли в учебной форме. `type="password"` скрывает символы, но не шифрует данные. Для передачи чувствительных данных нужны HTTPS и безопасная серверная обработка.
