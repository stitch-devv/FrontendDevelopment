# Урок 14 — Итоговый проект: сайт-портфолио

## Цель
Самостоятельно применить HTML и создать многостраничный сайт.

## Задание
Создай сайт начинающего разработчика минимум из двух страниц

## Главная index.html
Должны быть:
1. Базовая структура документа и `lang`.
2. `head` с `charset`, `viewport`, уникальным `title` и `description`.
3. `header` с названием сайта.
4. `nav` со ссылками на страницы.
5. Один основной `h1`.
6. Раздел «Обо мне» с несколькими абзацами.
7. Изображение с осмысленным `alt`.
8. Раздел навыков со списком.
9. Раздел проектов минимум с двумя проектами.
10. `footer` с копирайтом и ссылкой на контакты.

## Страница contact.html
Должны быть:
1. Корректная структура и собственный `title`.
2. Ссылка на главную.
3. Заголовок «Связаться со мной».
4. Ссылка `mailto:` и/или `tel:`.
5. Форма с полями имени, email и сообщения.
6. У каждого поля есть `label`, `id` и `name`.
7. Кнопка отправки с `type="submit"`.
8. `footer`.

Форма без настроенного сервера не отправит сообщение — здесь создаётся только HTML-интерфейс(макет).

## План выполнения
1. Создай папку и файлы.
2. Напиши структуру главной страницы.
3. Добавь семантические области и содержимое.
4. Создай страницу контактов.
5. Свяжи страницы навигацией.
6. Добавь изображение и список навыков.
7. Создай форму.
8. Проверь сайт в браузере и Nu HTML Checker.
9. Исправь ошибки.

## Чек-лист
- [ ] Обе страницы открываются.
- [ ] Все ссылки работают.
- [ ] Изображение загружается и имеет подходящий `alt`.
- [ ] Заголовки идут в логичном порядке.
- [ ] У формы есть подписи и `name`.
- [ ] У страниц разные `title`.
- [ ] Есть `lang`, `charset`, `viewport`.
- [ ] Нет повторяющихся `id`.
- [ ] Разметка проверена валидатором.
- [ ] Используются только материалы, на которые есть право.

## Что дальше?
Переходи к CSS: научишься оформлять страницу, управлять размерами, отступами, расположением и адаптивностью.
