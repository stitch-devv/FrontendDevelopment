# Урок 15 — Адаптивный дизайн

## Цель урока
Адаптировать макет к разной ширине окна просмотра.

## Теория и примеры
Адаптивный дизайн строится на гибких размерах, Grid/Flexbox и media queries. 
Точка перелома нужна там, где содержимое начинает плохо помещаться, а не обязательно на ширине конкретной модели устройства.

```css
.container {
    width: min(100% - 32px, 1100px);
    margin-inline: auto;
}
.cards {
    display: grid;
    grid-template-columns: repeat(3, minmax(0, 1fr));
    gap: 16px;
}
@media (max-width: 700px) {
    .cards { grid-template-columns: 1fr; }
    .nav { flex-direction: column; }
}
```

`@media` помогает устанавливать адаптивку 

В HTML нужен viewport:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

Проверяй навигацию, текст, изображения, кнопки и отсутствие горизонтальной прокрутки. 
Не запрещай масштабирование ради внешнего вида.

## Практика
Сужай окно браузера и добавляй media queries там, где элементы начинают мешать друг другу. 
Проверь узкий и широкий экран.

## Домашнее задание
Сделай адаптивный лендинг с навигацией, заголовком, кнопкой и карточками. Убедись, что контент не выходит за экран.
