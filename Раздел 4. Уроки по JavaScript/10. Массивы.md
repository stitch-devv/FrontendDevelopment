# Урок 10 — Массивы

## Цель урока
Хранить упорядоченные наборы значений.

## Теория и примеры
```javascript
const skills = ['HTML', 'CSS', 'JavaScript']
console.log(skills[0])       // HTML
console.log(skills.length)   // 3
```

Индексы начинаются с нуля

`console.log(skills[0])` - тут [] (фигурные скобки) нужны, чтобы вывести определенное значение внутри массива через его индекс; 0 - индекс значения 'HTML'

`console.log(skills.length)` - .length выводит длину массива(сколько в общем элементов в массиве)

```javascript
skills.push('React')  // добавить в конец
skills.pop()          // удалить последний
skills.unshift('Git') // добавить в начало
skills.shift()        // удалить первый
```

`const` не запрещает менять содержимое массива, но запрещает переназначать переменную. 
Методы `push`, `pop`, `shift` и `unshift` меняют исходный массив.

## Практика
Создай массив из пяти задач. Выведи первый и последний элементы, длину, добавь задачу и удали один элемент.

## Домашнее задание
Создай список покупок. Добавляй и удаляй элементы, затем выведи итоговый список и его длину.
