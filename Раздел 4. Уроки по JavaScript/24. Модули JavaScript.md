## Цель урока
Разделять код на файлы и импортировать нужные функции.

## Теория и примеры
В HTML подключи файл как модуль:

```html
<script type="module" src="js/main.js"></script>
```

Атрибут *type="module"* в теге script указывает браузеру, что скрипт является современным ES-модулем.
Это:
- Позволяет использовать ключевые слова import и export прямо в файле для разделения кода на независимые части
- аналогично атрибуту defer

В `math.js`:
```javascript
export function sum(a, b) {
    return a + b
}
```

В `main.js`:
```javascript
import { sum } from './math.js'
console.log(sum(2, 3))
```

Есть именованные экспорты и `export default`. Путь импорта должен быть корректным. 
Модули имеют собственную область видимости. Для локальной разработки ES-модули обычно запускают через локальный сервер(http://localhost). (У нас и так файл окрывается в локальном сервере когда нажимаем на Go live)
