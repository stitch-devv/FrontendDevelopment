# Урок 09 — Display и нормальный поток

## Цель урока
Понять стандартное расположение элементов и основные значения display.

## Теория и примеры
Блочные элементы обычно занимают отдельную строку; строчные располагаются в строке.

```css
.block { display: block; }
.inline { display: inline; }
.inline-box { display: inline-block; }
.hidden { display: none; }
.flex { display: flex; }
.grid { display: grid; }
```

`block` обычно начинает новую строку и принимает размеры. 
`inline` располагается в строке; ширина и высота работают не так, как у block.
`inline-block` остаётся в строке и поддерживает размеры. 
`display: none` убирает элемент с экрана. 
`visibility: hidden` скрывает элемент, но сохраняет его место.
`display: flex` превращает родительский элемент во флекс-контейнер, а все его прямые дочерние элементы становятся гибкими флекс-элементами. Это позволяет легко выстраивать их в строку или колонку, управлять размерами и выравниванием по двум осям
`display: grid` это система сеток в CSS, которая позволяет одновременно управлять строками и колонками
